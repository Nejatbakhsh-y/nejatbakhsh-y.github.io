# Website-YN-2026

A simple, responsive, one-page professional website for Yousef Nejatbakhsh.

## Sections

- Home
- About
- Research
- Projects
- Publications
- Teaching
- Professional Experience
- CV
- Contact

## Local Preview

The recommended method is the VS Code Live Server extension.

1. Open this project in VS Code.
2. Install the extension named **Live Server** by Ritwick Dey.
3. Open `index.html`.
4. Select **Go Live** in the VS Code status bar.

You may also open `index.html` directly in a browser, although Live Server is
better for automatic refresh during editing.
